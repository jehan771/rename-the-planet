One funny new name for a planet of our solar system, plus the why, in a single
line under 200 characters. Entry for the make.fun bounty
[Rename the Planet](https://make.fun/bounty/u-motasimfuad-rename-the-planet-094b0369).

## The line

> Mercury is now 'The Ex': scorching by day, freezing by night, and it starts a whole new year every 88 days.

107 characters, one line. The joke is the idea, not a pun on the name: Mercury
swings from scorching days to freezing nights, and a whole year there lasts
88 days — so it really does behave like an ex.

## Run

```sh
node entry/main.ts   # writes /output/entry.txt, asserts the 1–200 char gate first
```

The program asserts the gate (1–200 characters, single line, not whitespace)
before writing, then reads the file back and verifies it byte for byte.
